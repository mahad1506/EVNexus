# EVNexus

EVNexus is an electric vehicle research, comparison, finance, charging, and review platform.

## Project structure

- `frontend/` contains the React and Vite application.
- `backend/` is reserved for the server API.
- `AI/` is reserved for AI integration and assistant logic.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Build and lint the frontend from the same folder:

```bash
npm run build
npm run lint
```
